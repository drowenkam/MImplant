Use it offline on iPhone or iPad

After publishing to GitHub Pages:
  1. Open your GitHub Pages website using Safari, while connected to the internet.
  2. Tap Share, then Add to Home Screen.
  3. Launch the Home Screen icon once while online to finish saving the files, including PDFs; then use it without a connection.

You can also download and unzip this folder and open index.html locally on a computer. GitHub Pages is recommended on iOS for Home Screen installation and reliable offline access. Study progress is saved on each device, not automatically synchronised across devices.
